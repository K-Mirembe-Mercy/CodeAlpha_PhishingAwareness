# Contributing

Ideas are welcome: new quiz questions, more simulated emails, clearer explanations, accessibility fixes and translations.

1. Fork the repo and create a branch: `git checkout -b feature/short-description`
2. Edit content in `js/data.js` or logic in `js/app.js`.
3. Run `node tests/validate.js` and try the page locally (`python -m http.server 8000`).
4. Open a pull request describing the change.

## Content guidelines

- Use fictional brands, names and domains in simulations.
- Real cases must come from reliable public reporting and be summarised, not copied.
- Keep explanations short, practical and friendly. Teach, never shame.
- Follow the security rules in `SECURITY.md`.
